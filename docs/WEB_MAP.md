# Веб-карта, каркас (этап 1.2), 05.11.2026

Пункт 2 этапа 1 [продуктового плана](PRODUCT_PLAN_2026-10-31.md). Карта показывает исходные
слои задачи `porphyry_cu_balkhash` на сетке 1 км, их покрытие, источники и лицензии.
Щелчок по ячейке открывает карточку со значениями и происхождением: исходный файл, его
sha256 и манифест, который этот хеш подтверждает (`cache.json` подготовки признаков,
`run.json` прогона, `report.json` слепого теста).

Модель baseline не прошла слепой тест 05.11.2026 (вердикт `not_transferred`,
[BLIND_RESULT](BLIND_RESULT_2026-11-05.md)). Поэтому модельные растры зарегистрированы
только как `role: research`: по умолчанию скрыты, в API и легенде у них пометка
«исследовательский; не прошёл слепой тест». Слоя «перспективность» на карте нет.

## Устройство

```
web/layers.yaml ──► web/scripts/export_cogs.py ──► data/web/cogs/<id>.tif ──► TiTiler (тайлы)
configs/sources.yaml                                data/web/area_mask.tif
                                                    data/web/manifest.json ──► FastAPI /api/*
                                                                                   ▲
                                                    web/frontend (React + MapLibre)┘
```

- **Реестр** `web/layers.yaml`: id, файл и канал, название, единицы, роль, источники
  из `configs/sources.yaml`, манифест происхождения, палитра и диапазон. Пути к файлам
  есть только здесь. Новый слой (например, разброс ансамбля) добавляется записью в реестре.
- **Экспорт** (`web/api/jerqazyna_web/export.py`): COG на исходной сетке Albers, без
  перепроецирования (тайлы проецирует TiTiler, индексы ячеек совпадают с обучающими
  таблицами). DEFLATE без потерь, блоки 512, обзоры (`average` или `nearest` для масок).
  После записи значения COG сверяются с исходником. Хеш исходника сверяется с манифестом
  подготовки: если файл изменился после `prepare`, экспорт отказывает. Повторный запуск
  при том же рецепте и неизменном COG ничего не пересчитывает.
- **API** (`web/api/jerqazyna_web`): `create_app()`, тонкие роутеры, pydantic-модели ответов.
  При старте проверяет sha256 каждого COG по манифесту и не запускается при расхождении.
  - `GET /api/health` — состояние и число доступных слоёв.
  - `GET /api/layers` — реестр: лицензия, атрибуция, цитата, легенда, покрытие области,
    URL тайлов TiTiler, хеши. Не экспортированный слой приходит с `available: false`.
  - `GET /api/cell?lon=&lat=` — индексы ячейки (`row`, `col`, `cell_id = row·width + col`),
    центр в CRS сетки, значения всех слоёв окном 1×1 и их происхождение. 422 — точка вне
    сетки или некорректные координаты, 404 — на сетке, но вне области задачи.
- **TiTiler** `ghcr.io/developmentseed/titiler:2.4.0`: монтирует только `data/web/cogs`
  на чтение; STAC, mosaic и zarr отключены.
- **Фронтенд** `web/frontend`: Vite 7, React 19, MapLibre GL 5, TypeScript, версии
  зафиксированы в `package-lock.json`. Список слоёв с переключателями и прозрачностью,
  легенда, карточка ячейки, панель «Источники и лицензии». Подложка — растровые тайлы OSM
  с атрибуцией «© OpenStreetMap contributors».

## Лицензионные правила в коде

Проверяются при загрузке реестра (`registry.check_licenses`), нарушение — ошибка старта
экспорта и API (по [DATA_LICENSES](DATA_LICENSES_2026-11-05.md)):

- `usgs_fsu_geology` (ограничение ESRI; исключён из карты окончательно) и `geoboundaries`
  (векторные границы под ODbL) в слоях запрещены. Маска области из geoBoundaries лежит вне `cogs/`, TiTiler её не видит;
  API использует её только для ответа 404.
- Источник с `BY-SA` в лицензии (GEM, Maus) — только отдельным слоем с одним источником.
- У каждого источника показанного слоя должна быть формула атрибуции в разделе
  `attributions` реестра; лицензия и цитата берутся из `sources.yaml`. Для Copernicus DEM —
  формула для продуктов на основе WorldDEM-90 и отказ от ответственности.
- Для GLiM и GGMplus в атрибуции указано: показ для исследования и внутренних демонстраций,
  коммерция — после письменного разрешения.

## Запуск локально

Все данные и кэши — на H: (см. [AGENTS.md](../AGENTS.md)).

```powershell
. .\scripts\use-h-storage.ps1
.venv\Scripts\python.exe -m pip install -c requirements/py310-geo.txt -c requirements/py310-baseline.txt -c requirements/py310-web.txt -e ".[geo,baseline,web,dev]"

# 1. COG базовых слоёв (без --only — все включённые слои реестра)
.venv\Scripts\python.exe web\scripts\export_cogs.py --only dem_elevation --only magnetics_anomaly --only gravity_bouguer --only lithology_distance

# 2а. Всё в Docker (нужен .env с POSTGRES_PASSWORD и MINIO_ROOT_PASSWORD: compose
#     подставляет переменные всего файла). Карта: http://localhost:8080
docker compose --profile web up --build titiler api frontend

# 2б. Без сборки образов: TiTiler в Docker, API и фронтенд локально
docker compose --profile web up titiler
.venv\Scripts\python.exe -m uvicorn jerqazyna_web.app:create_app --factory --app-dir web/api --port 8000
cd web\frontend; $env:npm_config_cache = "H:\caches\JerQazynaAI\npm"; npm ci; npm run dev   # http://localhost:5173
```

Переменные API (`JERQAZYNA_WEB_*`, секретов нет): `DATA_DIR` (по умолчанию `data/web`),
`REGISTRY`, `SOURCES`, `TILES_URL` (адрес TiTiler для браузера, `http://localhost:8001`),
`TILES_DATA_DIR` (путь к `cogs/` внутри TiTiler, `/data/cogs`), `CORS_ORIGINS` (через
запятую; пустое значение отключает CORS, `*` запрещён). Фронтенд: `VITE_API_URL`,
`VITE_BASEMAP_URL`, `VITE_BASEMAP_ATTRIBUTION` (см. `web/frontend/.env.example`).

Тесты: `pytest -q tests/web` — синтетические растры в `tmp_path`; без fastapi тесты API
пропускаются, без rasterio — тесты экспорта. В CI это job `web-test` вместе с
`npm ci && npm run build`.

## Ограничения

- TiTiler принимает произвольный `url`, в том числе внешние адреса: это публичный
  тайловый сервер без белого списка. Для внешнего показа нужен прокси с белым списком
  файлов или собственная фабрика тайлов в API. До этого порты titiler, api и frontend
  в docker-compose.yml привязаны к 127.0.0.1 и из локальной сети недоступны.
- `tile.openstreetmap.org` допустим только для разработки и демонстраций (Tile Usage
  Policy OSMF); для внешнего показа — свой или платный сервер подложки.
- PostGIS и MinIO не используются: COG лежат на диске, манифест — JSON. Для нескольких
  задач и версий их место — MinIO с тем же манифестом.
- Не экспортированы: разломы GEM и маска выработок Maus (подготовлены прежним поколением
  кэша, хеш подтверждается только самим экспортом), растры модели. Команда экспорта та же.
- Атрибуция хранится в реестре, а не в `sources.yaml`, потому что модель каталога не
  содержит такого поля.
- Палитры легенды — опорные точки тех же colormap rio-tiler, а не их полная таблица.
