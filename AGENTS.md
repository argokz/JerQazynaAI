# Хранение данных

Пользователь установил правило: данные проекта хранить на H:, не на C:.

- Рабочий каталог: `H:\projects\JerQazynaAI`. Исходники данных, модели, результаты,
  отчёты и изображения сохранять внутри этого каталога на H:.
- Кэши и временные файлы: `H:\caches\JerQazynaAI`. Это относится к pip, Matplotlib,
  PROJ, Python bytecode и временным файлам тестов/обработки.
- Перед командами установки или создания окружений в PowerShell выполнить
  `. .\scripts\use-h-storage.ps1`. В существующих `.venv` и `.venv-emit` установлен
  startup-файл, направляющий кэши и временные файлы на H: даже из уже открытого приложения.
- Использовать прямые пути на H:. Переходы junction между C: и H: в этом окружении
  не работают; не создавать такие ссылки и не возвращать кэши в каталоги на C:.
- Установленные интерпретаторы Python могут оставаться на C:; это программные файлы.
  Переносить их или системные каталоги Windows в рамках переноса данных не требуется.
- Проверенные переносы и их хеши сохранять в `data/storage/`. Существующие научные
  данные, завершённые эксперименты и ограничения закрытого региона сохранять.
