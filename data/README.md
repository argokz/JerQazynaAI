# data/

Сырые и обработанные данные в git не хранятся. Структура:

- `raw/` — исходные файлы в том виде, как скачаны (USGS SIR 2010-5090-N, база порфировой меди USGS 2025, Sentinel-2, ASTER, DEM, EMAG2, WGM2012, геокарты).
- `interim/` — перепроецированные и обрезанные слои.
- `features/` — сетка признаков для задачи.

Для каждого файла в `raw/` записывайте источник, дату скачивания и SHA-256 в `data/manifest.csv` (этот файл коммитится).
